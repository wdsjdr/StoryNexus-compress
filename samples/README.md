# samples — 上下文压缩压测示例（多题材矩阵）

演示文枢的**上下文压缩（SWA/CSA/HCA）**在多种题材与语言上的效果：
古典演义（中文半文言）、西幻（英文原文）——附信息完整性评估体系说明。

## 目录

| 子目录 | 题材 | 语言 | 数据 | 压测要点 |
|---|---|---|---|---|
| `三国演义/` | 古典演义（cultivation） | 中文半文言 | 公版（罗贯中，明代）120 回 | 切章「第X回」、文言"X曰"模板、以字称人 |
| `wizard_of_oz/` | 西幻（western） | 英文原文 | 公版 *The Wonderful Wizard of Oz*（L. Frank Baum，1900）24 章 | 拉丁人名发现、英文断句、Chapter N 切章 |

各目录内含：`<书名>.txt`（公版原文，UTF-8）、`benchmark_report.md/json`（压测报告）、
`compressed/`（压缩产物样例 packet_ch*.json）。

## 复现

```bash
# 古典演义（三国演义，120 回）
python -m scripts.benchmark_1m \
  --src samples/三国演义/三国演义.txt --skill default \
  --key-entities "刘备,曹操,诸葛亮,云长,孔明"

# 西幻英文（绿野仙踪，24 章，拉丁人名）
python -m scripts.benchmark_1m \
  --src samples/wizard_of_oz/wizard_of_oz.txt --skill western \
  --key-entities "Dorothy,Scarecrow,Toto,Wizard"
```

## 题材适配说明

### 古典演义（第X回 / 文言）
- 切章正则支持「第X回」与「Chapter N/I」（罗马数字），容忍全角空格缩进。
- cultivation 模板含文言"X曰/对曰：“…”"对话与军事动词（引兵/率军/斩/破/围/袭）；
  默认 skill 已并入 generic 模板（"X道：“…”"白话说话模板）——对话事实显著增加。
- **以字称人**：高频用「字」（云长/孔明/玄德），全名（关羽/诸葛亮）词频反而低；
  关键实体建议字名同传。
- **证据 3（高频+跨章+人物语境）已全 profile 开放**（不再限 slice）——玄德类无姓氏人名可命中。

### 西幻（western profile，P2）
- **拉丁人名发现**：大写开头词 + 对话标签（said/asked/whispered）两侧语境 + 跨章 span，
  停用表过滤句首词/代词（The/He/She）。
- **中文音译名**：间隔号名（哈利·波特）双轨频率识别；无姓氏音译名（甘道夫）走证据 3。
- **西幻称谓**：骑士/法师/爵士/公爵/领主/女王…并入称谓证据。
- **动作模板**：施展/吟唱/召唤/拔出/骑上/签订/加冕/诅咒…；宾语放宽（巨鹰/咒语/战马等
  普通名词可作宾语，量词清洗；主语仍严格 ∈ 实体集）。
- **英文原文的事实提取**：启发式模板为中文句式（"X施展Y"），英文原文（"Gandalf cast a spell"）
  当前**不产出事实**——实体/说话人/断句层已适配，事实层依赖 LLM 双轨（`--llm-facts`）或
  后续英文模板迭代；报告显示事实 0 属预期。
- **冷库**：伏笔关键词支持英文时间词（next spring / in 3 years）与翻译体（来年/春天）；
  阵营登记新增"效忠/宣战"类谓词。

### motif 与伏笔为 0
cultivation/generic/western profile 无 motif 线索层（slice 专属）且伏笔登记依赖"约定"类事实
（西幻 promise 词 发誓/起誓/誓约 已加入）——按题材预期。
